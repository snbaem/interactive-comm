Pick a sample letter or upload a PDF

icsel finds each block of the letter (address, subject, date, body, ...), scores every layout, and renders a sample of the letter in the best one. Click a layout in the ranking to see the letter in that layout instead.

All sample data is synthetic (fictional company: Brightwater Utilities). Runs are kept in memory and in the server's working folder until the server stops.
